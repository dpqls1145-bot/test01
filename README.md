# AI 작품 포트폴리오

AI로 만든 이미지·영상·음악 작품을 보여주는 정적 웹사이트 갤러리입니다. 빌드 도구 없이 `index.html`을 열면 동작합니다.

## 내 작품으로 바꾸는 법

1. 작품 파일(이미지/영상)을 `assets/` 폴더에 넣습니다.
2. `works.js`를 엽니다.
   - `PROFILE`: 이름, 소개, 링크(`TODO` 표시된 부분)를 수정합니다.
   - `WORKS`: 샘플 항목을 실제 작품으로 교체합니다. `src`에 파일 경로를 넣고 `sample: true`는 삭제합니다.
3. 브라우저에서 `index.html`을 열어 확인합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 페이지 뼈대 |
| `style.css` | 디자인 (라이트/다크 테마, 반응형) |
| `script.js` | 갤러리 렌더링, 카테고리 필터, 상세 보기 |
| `works.js` | 프로필과 작품 데이터 (수정은 주로 여기서) |

## 기능

- 카테고리 필터, 작품 클릭 시 상세 보기(←/→ 이동, Esc 닫기)
- 이미지·영상 지원
- 라이트/다크 테마 전환, 모바일 대응

## 배포 (GitHub Pages)

저장소 Settings → Pages에서 배포할 브랜치와 `/ (root)`를 선택하면 공개됩니다.
