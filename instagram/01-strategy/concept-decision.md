# 컨셉 결정 기록

최종 수정: 2026-11-08 (초안)

## 확정 (사용자가 직접 답한 내용)
- 분야: 패션
- 얼굴 노출: 하지 않음 (필요 시 모자이크 정도)
- 핵심 콘텐츠: 색조합 + 아이템 추천
- 첫 소재: 상의·하의 색 매칭 (ACC 포함)
- 데일리룩(사진·릴스)도 하고 싶어 함

## 제안 (Claude 제안, 사용자 최종 확인 전)
- 계정 핵심 문장: "색조합을 알려주는 계정"
- 데일리룩은 별개 주제가 아니라 색조합을 보여주는 "증명형" 콘텐츠로 배치
- 실행 순서: 사진(캐러셀) 중심으로 시작 -> 데일리룩 소량 추가 -> 반응을 본 뒤 릴스 도입 여부 결정
- 기간과 빈도는 가안이며 실제 가능한 게시 빈도에 맞춰 조정

## 미정
- 타깃 (누구를 위한 계정인가)
- 스타일 (미니멀, 스트릿, 오피스룩 등)
- 촬영 방식 (직접 착용 / 옷만 따로 촬영)
- 주당 게시 빈도
- 수익화 방식 우선순위 (제휴, 공동구매, 협찬 등)

## 주의사항
- 협찬·제휴 게시물의 광고 표시 의무는 시작 전에 공정거래위원회 안내를 직접 확인할 것
- 사진은 직접 촬영을 기본으로 함 (저작권 문제 방지)
