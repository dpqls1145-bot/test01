# 색 매칭 리서치 노트 (1차)

작성일: 2026-11-09
방법: 웹 검색 3회 (영어 2, 한국어 1). 검색 결과 요약만 확인했고 각 원문 페이지를 열어 검증하지는 않았음.
상태: 미검증 자료. 게시물 제작 전 원문 확인 필요.

## 1. 기본 색 조합 방식
| 방식 | 설명 | 출처 |
|---|---|---|
| 모노크로매틱/톤온톤 | 한 색상 계열에서 명도·채도만 변화 | 영어 가이드 다수, W Korea |
| 유사색(analogous) | 색상환에서 이웃한 색. 실패 확률이 낮다는 설명이 있음 | 영어 가이드 다수 |
| 보색(complementary) | 색상환에서 마주 보는 색. 대비가 가장 강함 (예: 초록/분홍, 파랑/주황, 노랑/보라) | 영어 가이드 다수 |
| 톤인톤 | 색은 다르게, 채도·농도는 비슷하게 | 한국 매체 기사 |
| 스플릿 보색, 트라이어딕 | 일부 가이드에서 추가로 소개 | 영어 가이드 일부 |

## 2. 상의·하의 매칭 팁 (검색 결과 기준)
- 톤온톤이 부담되면 상하의만 먼저 맞추는 방법이 제안됨 (예: 그레이 니트 + 더 진한 그레이 와이드 팬츠)
- 같은 계열이라도 명도 차이를 주는 방식이 소개됨 (예: 짙은 브라운 스커트 + 한 톤 밝은 브라운 톱)
- 채도가 높은 색은 베이지, 아이보리, 샌드 같은 뉴트럴 위에 쓰면 부드러워진다고 함
- 온도 대비 예시: 차콜 그레이 아우터 + 버터 옐로우 머플러나 이너
- 채도를 약간 낮춘 색이 선명한 색끼리 조합하는 것보다 부담이 덜하다고 함

## 3. ACC(액세서리) 활용: 60-30-10 규칙
- 주색 약 60%, 보조색 약 30%, 포인트 약 10%
- 포인트 색은 신발, 가방, 주얼리, 스카프 같은 작은 아이템에 쓰는 것으로 소개됨
- ACC는 전체 팔레트와 어울리게 고르라는 조언이 있음
- 금속 ACC(시계 등), 브라운·블랙 가죽은 색 개수에 넣지 않는 중립으로 취급된다는 설명이 있음
- 비율은 엄격한 수치가 아니라 대략적 기준이라는 설명이 있음

## 4. 출처끼리 의견이 갈리는 부분
- 모노크로매틱에 뉴트럴(검정, 흰색, 회색)을 섞어도 되는가: 허용한다는 가이드와 톤온톤에는 잘 안 맞는다는 가이드가 공존
- 포인트 색을 몇 개까지 허용하는가: 대부분 1개, 일부 블로그는 2번째 포인트 색을 허용
- 위 항목은 콘텐츠로 만들 때 "정답"처럼 단정하지 말 것
