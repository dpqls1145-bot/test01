# 계정 개설 체크리스트 (초안)

작성일: 2026-11-09
상태: 사용자가 정해야 하는 항목은 "미정". 아래 제안은 일반 원칙에 따른 Claude의 제안이며 인스타 정책으로 검증하지 않았음.

## 1. 개설 전에 정할 것
| 항목 | 상태 | 메모 |
|---|---|---|
| 계정 이름(표시 이름) | 미정 | 검색에 걸릴 키워드 포함 여부 고려 (예: 색조합, 코디) |
| 사용자 ID | 미정 | 읽기 쉽고 말하기 쉬울 것, 자주 바꾸지 않을 것 |
| 프로필 사진 | 미정 | 얼굴 비공개이므로 로고, 색 팔레트 이미지, 아이템 사진 등 |
| 소개글(바이오) | 미정 | "누구에게 무엇을 보여주는 계정인지" 한 문장 + 업로드 주기 |
| 대표 색감/템플릿 | 미정 | 게시물마다 같은 레이아웃과 폰트 사용 |

## 2. 계정 유형
- 인스타에는 일반 계정과 프로페셔널(크리에이터/비즈니스) 계정이 있는 것으로 알고 있음
- 프로페셔널 계정은 인사이트(조회·저장 지표)를 볼 수 있는 것으로 알고 있으나 설정 메뉴 이름과 조건은 앱에서 직접 확인할 것
- 29CM 큐레이터 조건이 확인되면 계정 유형 요건이 있는지도 함께 확인할 것

## 3. 첫 게시 전 준비 (제안)
- 비어 있는 계정은 방문자가 컨셉을 파악하기 어렵다고 판단하여, 게시물을 몇 개 만들어 두고 시작하는 방식을 제안함
- 개수 기준은 정해진 것이 없음. 사용자가 감당 가능한 수로 정할 것 (잠정 6~9개, 미정)
- 첫 게시물 소재: 상의·하의 색 매칭(ACC 포함), 활용도 높은 기본 색 조합
- 트렌드 색은 ACC 포인트로 활용 (03-content 노트 참고)

## 4. 운영 기록 (06-analytics 연계)
- 주 1회 기록할 지표 예시: 게시물별 저장 수, 도달, 팔로워 증감
- 어떤 형식이 반응이 좋은지 비교하려면 게시 일시, 소재, 형식을 같이 적을 것

## 5. 목표 연계
- 최종 목표: 29CM 큐레이터 가입 및 체험단 신청 (00-overview/goals.md)
- 가입 조건이 확인되지 않았으므로 조건 확인 후 이 문서의 준비 항목을 조정할 것

## 6. 아직 모르는 것
- 인스타 프로페셔널 계정의 현재 설정 방법과 정책 세부 사항
- 29CM 큐레이터 요건
- 사용자의 주당 제작 가능 시간
